01

Overview

two builds, one engine

Work is the audio_fx build. It drops into a Signal Chain slot or a Master FX slot and processes whatever is upstream.

Overwork is the overtake build. It takes over Move’s whole surface and runs the same twenty-six machines on the live input — mic, line, or USB-C — with a step sequencer driving parameter locks.

Why the surface maps so cleanly

Tonverk is an eight-encoder-per-page instrument with sixteen trig keys. Move has eight knobs and sixteen dedicated step buttons. The mapping isn’t an approximation — it’s the same instrument shape, so the gesture that defines Elektron sequencing survives intact.

Correspondence

Clean room Every machine is written from Elektron’s published Tonverk user manual — documented parameter names, ranges and descriptions only. No Elektron code and no factory content, and this is not a bit-exact emulation. The DSP, filter topologies, reverb tank and pitch-shifter windowing are all our own.
02

Signal flow

two inserts in series

Both slots run in series. Each holds one machine. The two FX LFOs reach any slot parameter, and in Overwork the sequencer’s parameter locks sit between the base value and the LFOs.

A lock sets the value; the LFO then moves around whatever the lock set. Pointing a lock and an LFO at the same parameter is well defined, not a fight.

03

The p-lock gesture

try it below

Hold a step button. Turn a knob. That parameter is now locked on that step. Release the step and the knob goes back to editing the base value.

Interactive — FX 1 : Chrono Pitch hold a step, then drag a knob

No step held. Turning a knob edits the base value for the whole pattern.

What a trig does when it fires Each firing trig is a complete snapshot: parameters it locks take their locked value, and parameters it does not lock revert to base. A trig whose condition fails changes nothing at all. That is a deliberate choice, not an inevitability — it makes a pattern readable by looking at one step.

05

The machines

26 · knob labels A–H

Twenty-one process what reaches the slot; five are sources — they replace the slot’s input with a sample instead of treating it, which is what lets a Work slot originate audio rather than only colour it. Machine order is the preset format and is append-only. Loading a machine installs its own defaults, and switching machines clears that slot so no reverb tail leaks into whatever loads next.

06

Samples

8 seconds · stereo

Five machines read a sample rather than the slot’s input. One sample is loaded at a time and every source machine shares it, so switching between Single Player, Subtracks and Wavefinder auditions the same audio three ways.

Loading one

In Overwork, hold Shift and press the slot pad (row 4, third from the left). The jog scrolls, a jog click loads, and the same Shift + slot pad closes the browser.

The browser walks UserLibrary/Samples and UserLibrary/Recordings, four levels deep — deep enough to reach Schwung’s own resampler and skipback folders, which file by date.

Sample rate is not converted. A 48 kHz file plays about a tone sharp, because playback follows the file rather than resampling it. That is what a sampler does, and what TUNE is for.

What a source machine is

Every machine before Single Player treats what arrives at the slot. A source machine replaces it. Put one in FX 1 and the slot stops being an insert and starts being an instrument, with FX 2 still processing what it makes.

With no sample loaded a source machine is silent rather than noisy — an empty slot makes no sound, it does not pass its input through.

Triggering

A full trig fires the voice; a lock trig deliberately does not, matching Elektron’s trigless lock. An incoming note fires it too, so the machines are playable from a keyboard or Move’s pads with the sequencer stopped.

Notes set pitch, with note 60 as unity — C3 plays the sample as recorded and everything else transposes from there.

What Tonverk does that this does not

Three of the five are adaptations, and the machine pages above say which. Multi Player has no multi-sampled instruments — there is one buffer, so every note plays it transposed. Subtracks has the playback controls but not the eight sequencer subtracks and supertrack that give it its name; Work is a two-slot chain, not an eight-track sampler. Wavefinder has no SD card and no wavetable slots, so the loaded sample is the wavetable, read as a series of 2048-frame waves. Shape alone needed no adaptation, because a Work slot is exactly the bus insert the manual puts it on.

Lockable parameters

Sixteen slot parameters — eight per slot — plus both machine selects and the global dry/wet. Locking a machine select swaps the machine for that step.

Retrig, precisely Retrig restarts the FX LFOs and the filter envelope. It does not stutter the audio — the Degrader’s FREZ parameter is the machine for that.

Feedback protection

Overwork reads the mic and puts the result on the speakers, which is a feedback loop waiting to happen. schwung’s own guard only walks Signal Chain slots, so it never sees an overtake module at all — Overwork carries its own.

Whenever the speakers are live with nothing plugged into the input jack, the live input is muted automatically and the screen says so. Shift + the Fill pad overrides it, and the override stands until the jack state itself changes, so the guard never fights you.

The input is muted at the input, not the output — so reverb tails and delay repeats ring out and decay naturally instead of being cut dead.

Pattern bank and song mode

Sixteen patterns; Shift + a step button selects one, the way it works on the hardware. Song rows chain patterns with a repeat count and an optional length override, and pad 83 switches between pattern and song playback. Each pattern carries its own length and page mask, so switching pattern switches those too.

Undo, redo, memorize

Pad 81 undoes the last destructive edit and Shift+tap redoes it; pad 82 recalls on a tap and memorizes on a hold. Every transform, clear and recall takes a snapshot first.

Trig types

A full trig applies its locks and restarts the LFOs and modulation envelope. A lock trig applies its locks and nothing else — Elektron’s trigless lock. With no voices to place notes for, that is the distinction that carries over.

Live recording

Shift + Play arms it. With the sequencer running, turning a knob writes a parameter lock onto whichever step is playing and arms a trig there — the same path a MIDI CC takes, so an external controller records locks too. The play pad turns red while armed.

Probability

Every step carries its own probability, 1–100, separate from its trig condition — both gates must pass. Shift + the pattern-page pad selects probability mode, then hold a step and turn the jog.

Modulation

Three FX LFOs and an AHD modulation envelope that restarts on every firing trig. Resolution order is base → parameter lock → envelope → LFOs, so each stage rides the one before it.

MIDI CC

External CC only — Move’s own encoders arrive as internal CCs and are ignored, and a duplicate inside two blocks is dropped.

Presets

Shift + jog click opens the preset browser. The jog scrolls, a click loads, and the top entry saves a new one; the clear pad deletes the selected preset. Presets are stored outside the module directory, so reinstalling Overwork does not remove them.

Pattern length runs to 64 steps across four pages. The sequencer also exists in the chain build, where it defaults to off — a sequenced FX in a Signal Chain slot is a real use, not an accident.

08

Install

schwung-manager
  1. Open schwung-manager on your Move — usually move.local:7700.
  2. Choose Install Custom Module.
  3. Point it at timncox/schwung-work for Work, or timncox/schwung-overwork for Overwork. Either repo URL, or upload a release tarball directly.
  4. Rescan. Work appears as an audio effect in the Signal Chain and Master FX; Overwork appears in the overtake menu.
If you are on schwung v0.11.4 or older Overwork declares audio_in, which on those versions can raise a launch-gate confirmation the tool cannot answer once it owns the surface (schwung issue #158). Remove that flag from its module.json, or keep line-in or headphones plugged in, which clears the condition entirely.

After updating a module already on the device, fully exit it — Shift + Volume + jog click from inside — and relaunch. Pressing Back only suspends the session, which resumes the old code.
